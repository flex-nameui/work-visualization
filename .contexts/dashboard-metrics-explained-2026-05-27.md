# 패스키 일정 대시보드 — 지표(metric) 쉽게 이해하기

> 방향 B(타임라인 중심)에 들어갈 지표와 위젯이 각각 무엇을 보여주고, 어떻게 계산되는지를 쉬운 말로 설명하는 문서입니다.
> 읽으시다가 **아직 헷갈리는 부분**이나 **이건 빼/넣고 싶다** 하는 부분에 인라인 주석을 남겨주세요. 그걸 반영해서 계획서를 확정합니다.
> 아래 숫자들은 전부 **설명용 가짜 예시**입니다(아직 실제 노션 데이터를 불러오기 전이라서요).

---

## 0. 먼저: "지표(metric)"가 뭐야?

지표 = **현재 상황을 숫자 하나로 요약한 것**입니다.

예를 들어 "완료율 61%"라는 지표는 "전체 작업 중 61%가 끝났다"를 숫자 하나로 말한 겁니다. 대시보드(dashboard, 여러 지표를 한 화면에 모은 현황판)는 이런 숫자와 그림을 한 곳에 모아서 **"지금 일정이 잘 가고 있나?"를 1~2초 안에 판단**하게 해주는 도구예요.

### 우리가 가진 데이터부터 짚기

노션 DB의 작업(task) 한 개는 이런 정보를 가집니다:

| 항목 | 뜻 | 예시 |
|------|-----|------|
| 제목 | 작업 이름 | "operation-api 진행 (PR까지)" |
| 트랙 | 어느 영역 일인지 | 관리자 |
| 종류 | 작업의 성격 | 개발 |
| status | 진행 상태 (셋 중 하나) | 안 시작 / 진행 중 / 완료 |
| 일자 | 시작일 ~ 종료일 | 5/27 ~ 5/28 |

작업이 약 18개 있고, **모든 지표는 이 18개를 세거나 날짜를 계산해서** 만들어집니다. 마법이 아니라 단순 산수예요.

아래 설명에서 쓸 **공통 가짜 예시**를 하나 정해두겠습니다:

- 전체 작업: **18개** (완료 11개, 진행 중 3개, 안 시작 4개)
- 전체 일정: **5/1 ~ 5/30** (총 30일)
- 오늘: **5/27**

---

## 1. 맨 윗줄 — KPI 카드 (큰 숫자 3~4개)

KPI = Key Performance Indicator(핵심 성과 지표), 그냥 **"가장 중요한 숫자"**라는 뜻입니다. 카드 한 장에 큰 숫자 하나씩 올려서 맨 위에 둡니다. 후보가 4개 있는데, 하나씩 풀어볼게요.

### (가) 작업 진척률 — "일이 얼마나 끝났나"

- **뜻**: 전체 작업 중 완료된 작업의 비율
- **계산**: 완료 작업 수 ÷ 전체 작업 수
- **예시**: 18개 중 11개 완료 → 11 ÷ 18 = **61%**

### (나) 시간 진척률 — "시간이 얼마나 지났나"

- **뜻**: 전체 일정 기간 중 지금까지 흘러간 시간의 비율
- **계산**: (오늘 − 시작일) ÷ (종료일 − 시작일)
- **예시**: 기간 5/1~5/30 중 오늘이 5/27 → 26일 ÷ 29일 = **90%**

### ★ (가)와 (나)를 같이 보면 "일정 상태"가 보입니다 (이게 핵심)

이 두 숫자를 나란히 두는 게 이 대시보드의 가장 중요한 장치입니다.

| 상황 | 의미 |
|------|------|
| 작업 진척률(61%) **<** 시간 진척률(90%) | 시간은 90% 지났는데 일은 61%만 끝남 → **지연 위험** |
| 작업 진척률 ≈ 시간 진척률 | 페이스 정상 |
| 작업 진척률 **>** 시간 진척률 | 계획보다 앞서가는 중 |

즉 "61% vs 90%"만 봐도 "어, 시간 대비 일이 덜 됐네, 서둘러야겠다"가 즉시 판단됩니다.

### (다) 잔여 일수 — "데드라인까지 며칠?"

- **뜻**: 오늘부터 마지막 종료일까지 남은 날 수
- **계산**: 마지막 종료일 − 오늘
- **예시**: 오늘 5/27, 마지막 종료일 5/30 → **3일 남음 (D-3)**

### (라) 오늘 활성 작업 수 — "오늘 동시에 굴러가는 일이 몇 개?"

- **뜻**: 오늘 날짜가 시작일~종료일 사이에 걸쳐 있는 작업 수 (= 오늘 진행되고 있어야 할 작업)
- **예시**: 오늘 5/27에 기간이 걸쳐 있는 작업이 4개 → **오늘 활성 4건**
- 너무 많으면 한 번에 너무 많은 일을 벌인 것(과부하) 신호

> **(추가 후보) 지연 작업 수**: 종료일이 이미 지났는데(예: 종료일 5/25 < 오늘 5/27) 아직 완료가 안 된 작업의 수. "늦은 일이 몇 개인가"를 직접 보여줘서 가장 직관적입니다.

### → 여기서 정하실 것

카드는 **3~4개가 적정**입니다(너무 많으면 어디 봐야 할지 혼란). 아래 후보 중 골라주세요:

- (가) 작업 진척률
- (나) 시간 진척률
- (다) 잔여 일수
- (라) 오늘 활성 작업 수
- (추가) 지연 작업 수

**제 추천**: (가) 작업 진척률 + (나) 시간 진척률 + (다) 잔여 일수 + (추가) 지연 작업 수
→ 이 4개면 "얼마나 했나 / 시간 대비 괜찮나 / 며칠 남았나 / 늦은 거 있나"가 한 줄에 다 보입니다.

## 2. Gantt 타임라인 — 이 대시보드의 메인 그림

Gantt(간트) 차트 = **작업을 시간축 위의 가로 막대로 그린 일정표**입니다.

- **가로축**: 날짜 (왼쪽 → 오른쪽으로 시간이 흐름)
- **막대 하나**: 작업 하나. 시작일 위치에서 시작해 종료일 위치까지 이어지는 가로 막대
- **막대 색**: 상태를 뜻함 → 완료 초록 / 진행 중 파랑 / 안 시작 회색
- **세로 줄(레인, lane)**: 트랙 6개(등록/인증/관리자/프론트/메트릭/마일스톤)를 위아래로 묶음. "어느 영역이 언제 바쁜가"가 보임
- **오늘선(today line)**: 오늘 날짜 위치에 세로선 하나. 이 선 **왼쪽(이미 지난 시점)인데 아직 회색이나 파랑인 막대 = 늦어진 작업**

```
        5/20    5/24    5/27(오늘)   5/30
          |       |        |          |
 등록   ███████░░░░         |              ← 초록(완료)
 인증        ████████▓▓▓    |              ← 파랑(진행 중), 오늘선 넘김
 관리자             ░░░░░░░ |              ← 회색(안 시작)
 프론트   ██████████        |
 메트릭                  ▓▓▓|▓▓▓           ← 오늘 걸쳐 진행 중
                            ┊
                         오늘선
```

**답하는 질문 (한 그림에 4개 동시)**: 지금 어디까지 왔나 / 뭐가 남았나 / 어디가 병목인가 / 오늘 뭘 하고 있나

---

## 3. 트랙별 진행률 막대 — 영역별 요약

- **무엇**: 트랙마다 가로 막대 1줄. 막대 안을 **완료(초록) / 진행(파랑) / 대기(회색)** 3색으로 채움
- **계산**: 그 트랙에 속한 작업들을 상태별로 세서 비율로 채움
- **예시**: 인증 트랙 작업 5개 = 완료 2 + 진행 1 + 대기 2 → 막대가 40% 초록 + 20% 파랑 + 40% 회색

```
 등록   ██████████░░  완료 5 / 진행 0 / 대기 1
 인증   ████░░░░░░░░  완료 2 / 진행 1 / 대기 2
 관리자 ███████░░░░░  완료 3 / 진행 1 / 대기 1
```

- **답하는 질문**: 어느 트랙이 뒤처졌나?
- **주의**: 트랙마다 작업 수가 달라서 %만 비교하면 오해할 수 있어, 옆에 "2/5" 같은 **실제 개수도 함께** 표기합니다.

---

## 4. Kanban 파이프라인 — 작업이 거쳐가는 단계별 현황

칸반(Kanban) = **작업이 거쳐가는 단계별로 몇 개가 있는지 보여주는 보드**입니다.

- **무엇**: 작업 "종류"(개발 → PR 업로드 → 리뷰 대기 → 리뷰 반영 → 마일스톤)를 작업이 거치는 단계로 보고, **단계마다 작업이 몇 개씩 있는지** + 각 단계 안에서 완료/진행/대기가 몇인지
- **예시**:

```
 개발(6)   PR 업로드(3)   리뷰 대기(5)   리뷰 반영(2)   마일스톤(2)
  ▓▓▓        ███            ░░░░░          ██            ██
```

- **답하는 질문**: 작업이 어느 단계에 몰려 있나? (예: '리뷰 대기'에 5개 쌓이면 리뷰가 병목)

---

## 5. 정리 — 그래서 무엇을 정하면 되나

방향 B의 위젯 4개 중 **Gantt 타임라인 / 트랙별 진행률 막대 / Kanban 파이프라인**은 그대로 갑니다.
**KPI 카드에 어떤 숫자 3~4개를 올릴지**만 골라주시면 됩니다.

- [ ] 작업 진척률
- [ ] 시간 진척률
- [ ] 잔여 일수
- [ ] 오늘 활성 작업 수
- [ ] 지연 작업 수

(제 추천: 작업 진척률 + 시간 진척률 + 잔여 일수 + 지연 작업 수)

이 문서가 이해되고 KPI까지 정해지면, 그걸 반영해서 최종 구현 계획서를 작성하겠습니다.
